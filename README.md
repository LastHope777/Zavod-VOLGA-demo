# Завод ВОЛГА: демо-сайт

Статический сайт для показа: главная с фильмом по цеху, 29 внутренних страниц, 3D-модели изделий.

Render: New > Static Site, этот репозиторий, Build Command `echo ok`, Publish Directory `public`.
Или Blueprint по `render.yaml`.

Демо закрыто от поисковиков (`public/robots.txt`).
